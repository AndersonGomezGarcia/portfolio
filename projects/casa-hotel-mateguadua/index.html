Casa Hotel Mateguadua Website - Sitio web para Casa Hotel Mateguadua

Página web para un hotel en Apartadó, Antioquia. Incluye información sobre habitaciones, ubicación, contacto y un carrusel de imágenes. Utiliza Bootstrap para el diseño y tiene integración con WhatsApp para reservas.

Enlaces Visitar

El sitio web para Casa Hotel Mateguadua es una plataforma diseñada para proporcionar información completa sobre el hotel, incluyendo detalles sobre habitaciones, servicios y opciones de reserva.

Características principales

  • Diseño responsivo utilizando Bootstrap.
  • Integración con WhatsApp para reservas rápidas.
  • Galería de imágenes del hotel y sus instalaciones.
  • Sección de preguntas frecuentes y contacto.

Tecnologías utilizadas:

  • HTML, CSS y JavaScript para el desarrollo front-end.
  • Bootstrap para el diseño responsivo.
  • Firebase para la gestión de reservas y datos.
